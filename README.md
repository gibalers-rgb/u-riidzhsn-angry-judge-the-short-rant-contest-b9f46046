# Angry Judge: The Short Rant Contest

A make.fun entry: a deterministic Python 3.13 program (stdlib only, no
network, no API key) that writes one short, funny rant about an everyday
annoyance — the elevator close-door button that has never once hurried a
door — to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

## Entry

> The close-door button in the elevator is a lie. I have pressed it four thousand times and the doors have never once hurried. It exists so I can feel powerful while we wait for a man three floors up hauling a trombone. I press it every day. I will press it again tomorrow. Some people pray. I press the button.

309 characters — inside the 1–400 character gate.
